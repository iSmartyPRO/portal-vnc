# PortalVNC

Защищённый интерактивный удалённый доступ к Windows-компьютерам — аналог VNC с
улучшенными возможностями под администрирование парка машин в доменной и
бездоменной среде.

- Доступ членам локальной группы «Администраторы» по SID (`S-1-5-32-544`) —
  работает на любой локали Windows.
- Вход учётной записью Windows (пароль проверяет сама ОС), без своего хранилища.
- Канал — TLS со взаимной проверкой сертификатов: посторонний VNC-клиент
  подключиться не может.
- Нативные exe, статическая линковка, минимум файлов рядом. Без .NET и прочих
  рантаймов.

## Карта репозитория

| Папка | Назначение |
|---|---|
| `protocol/` | Общий модуль: транспорт mTLS, рукопожатие, версии, SID-авторизация |
| `agent/` | Агент-служба (сервер) на целевой машине: захват экрана, ввод, конфиг |
| `viewer/` | Клиент-просмотрщик (Windows, окно Win32) |
| `tools/` | Скрипты: генерация dev-сертификатов, локальный запуск |
| `docs/` | Спецификация дизайна и планы реализации |

Шлюз для портала и браузерный просмотрщик, служба/Secure Desktop, терминальный
сервер и MSI-установщик — отдельные планы (см. `docs/superpowers/plans/`).

## Сборка

Требуется: Visual Studio Build Tools 2022 (C++), Windows SDK 10, CMake ≥3.25,
vcpkg. Подробности — `cmake/toolchain-notes.md`.

```powershell
cmake --preset default
cmake --build --preset default
```
