## Ручная проверка (за вами — нужен ваш пароль Windows)

Вход настоящей учётной записью Windows и показ живого рабочего стола требуют
вашего пароля, который я не ввожу. Проверьте сами:

```powershell
# из корня репозитория, в окне с правами администратора
cmake --build --preset default
powershell -ExecutionPolicy Bypass -File tools\run-local-slice.ps1
# затем выполнить напечатанную команду pvnc-viewer (спросит пароль)
```

Критерии (отметьте):
- [ ] виден собственный рабочий стол, обновляется;
- [ ] движение мыши и ввод с клавиатуры из окна действуют на рабочем столе;
- [ ] вход не-администратором (если есть такая учётка) → отказ `not a member of Administrators`.

> Примечание: этот срез — обычный консольный агент и захват обычного рабочего
> стола. Служба Windows, экран блокировки/UAC, терминальный сервер и MSI —
> следующие планы.
